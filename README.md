# 클래스매니저 — 유료 클래스 운영자를 위한 수업 운영 도구

학원·공방·PT샵·쿠킹클래스 등 **수강료를 받는 사업자**가 매일 쓰는 운영 도구 데모입니다.
엑셀·카톡으로 흩어져 있던 **수강생 관리, 수업 출석 체크, 수강료 수납 현황**을 한 화면에서 끝냅니다.

## 🌱 왜 만들었는가

학원 원장님, 공방 사장님, PT샵 원장님 — 하루 종일 사람을 가르치고 땀 흘리는데,
정작 그 수고는 **엑셀 파일 5개** 속에 묻혀 있었습니다.
누가 결제했는지 몰라 밤늦게까지 정리하고, 미납자를 찾느라 수업 준비 시간을 뺏기고.

원장님의 진짜 일은 수업이지, 엑셀이 아닙니다.
그래서 만들었습니다. **수강생 관리, 이제 걱정 마세요.**

우리의 약속: **"우리는 사장님의 일을 세상이 알아주게 만듭니다."**
높은 가치는 느끼는 사람들에게 전달되어야 합니다.
여기에 쌓인 데이터는 10년 후에도 원장님의 것입니다 —
언제든 내려받아 가세요. 가게를 물려주는 날, 신뢰까지 함께 이어받으세요.

우리가 지키는 7가지: 사람을 사람으로 · 정직 · 다크패턴 금지 · 따뜻함 · 신뢰 · 겸손 · 인내

## 실행 방법

```bash
cd 02-meetup-manager
bash run.sh
```

- 브라우저에서 **http://localhost:5002** 접속
- **포트 충돌 시**: `run.sh`가 5002번이 사용 중이면 자동으로 **다음 빈 포트**로 실행합니다.
- 첫 실행 시 데모 데이터(강좌 3개·수강생 19명·수업 12회·10월 수강료 청구서)가 자동 생성됩니다.
- 종료: 터미널에서 `Ctrl+C`
- E2E 테스트: `python3 tests/test_e2e.py`

요구 사항: Python 3.8+ · Flask (외부 API·유료 서비스·CDN 없음, 완전 오프라인 동작)

## 타겟 고객

| 고객 | 현재의 고통 | 이 도구가 주는 가치 |
|---|---|---|
| 학원·공방 원장 | 수강료 미납자를 카톡·수첩으로 추적, 월말 정산에 반나절 소요 | 미납자 목록 + 원터치 입금 확인, 월별 수납률 자동 집계 |
| PT샵·요가원 운영자 | 수업별 출석을 종이 출석부에 기록, 누가 빠졌는지 파악 불가 | 수업 등록 시 출석부 자동 생성, 출석/결석/미정 원터치 체크 |
| 쿠킹·베이킹 클래스 강사 | 재료비 N빵 계산을 계산기로 반복, 공지를 단체 카톡에 묻힘 | 총액 입력 → 1인당 금액 자동 계산, 강좌별 공지 게시판 |
| 당근모임 유료 클래스 호스트 | 모임 앱에는 결제·정산 기능이 없음 | 모임 운영 + 수강료 정산까지 한 번에 |

**핵심 어필 포인트**
1. **수강료 미납 제로화**: 대시보드에서 이번 달 미납자와 미납 금액을 즉시 확인, "입금 확인" 버튼 하나로 수납 처리
2. **월별 수납률 시각화**: 강좌별·전체 수납률을 진행률 바로 표시 — "이번 달 장사가 얼마나 됐는지" 한눈에
3. **수업 등록 → 출석부 자동 생성**: 수강생 전원의 출석 상태(출석/결석/미정)가 자동 세팅, "전원 출석" 일괄 처리 지원
4. **N빵 정산기**: 재료비·회식비 총액 입력 → 인원수 자동 분할 → 개인별 청구서 일괄 생성
5. **모바일 반응형**: 매장·스튜디오 현장에서 스마트폰으로 바로 출석 체크·입금 확인 가능

## 기능 목록

- **첫 화면 (짜증 오프닝)**: "수강생 관리 엑셀이 5개예요. 누가 결제했는지 모르겠어요." — 숫자로 보여주고 "이제는 이렇게"로 전환
- **원장님 오늘 브리핑** (`/briefing`): 시간대별 인사(아침 "오늘도 힘내세요 😊"/밤 "오늘 수고하셨어요"), 오늘 수업·이번 달 수강료·오늘 할 일, "이번 달 N명의 학생이 원장님 덕분에 성장했어요"
- **가치 계산기** (`/calculator`): 수강생 수·강좌 수 입력 → "이걸 쓰면 월 ○○만원 아껴요"
- **월간 리포트** (`/report`): 수업·출석률·수납률·신규 수강생 + 지난달 비교 + 비슷한 가게 벤치마크(데모 기준 표기)
- **성장 시뮬레이터** (`/simulator`): 막대를 움직이면 월 추가 매출 미리보기
- **추천 리워드** (`/referral`): 추천 코드·추천 문구 복사·단톡방 공유, 추천 기록 시 배지
- **배지** (`/badges`): 첫 걸음·모임의 시작·완납의 달인·꾸준한 원장님·소문의 주인공·든든한 기록가
- **우리의 약속** (`/about`): 사명 선언문, 왜 만들었는가, 10년 데이터 소유, 가게 이어받기, 가치 7원칙
- **가게 이어받기** (`/export`): 전체 데이터 JSON 내려받기
- **축하 애니메이션**: 새 수강생 등록 시 컨페티 + 환영 메시지
- **대시보드**: 이번 달 수강료 수납률, 미납 금액, 다음 수업 D-day 일정, 미납자 목록(원터치 입금 확인), 최근 공지
- **강좌 관리**: 개설(강좌명·카테고리·월 수강료·정기 일정·소개)/수정/삭제, 강좌별 수강생·수업·수납 현황 요약
- **수강생 관리**: 등록(이름·연락처·메모)/휴원·복원/삭제
- **수업 관리**: 일정 등록(날짜·시간·장소·메모), 수업별 출석 체크(출석/결석/미정), 전원 출석 일괄 처리
- **수강료 정산**: 월별·강좌별 수납 현황, 일괄 청구(1인당 금액 / 총액 N빵), 개인별 금액 수정·입금 확인·청구서 삭제, 중복 청구 방지
- **공지사항**: 전체/강좌별 공지 작성·조회·삭제
- **에러 처리**: 모든 입력값 검증, 존재하지 않는 리소스 접근 시 404 페이지, 서버 오류 시 500 페이지 (traceback 노출 없음)

## 기술 스택

- Backend: Python Flask (단일 `app.py`)
- DB: SQLite (`classmanager.db`, 첫 실행 시 자동 생성 + 시드)
- Frontend: 순수 HTML/CSS (모바일 우선 반응형, 외부 CDN·JS 라이브러리 없음)
- 한국어 UI
